# 🧩 Sudoku OCR Solver

A futuristic, high-performance Sudoku Solver built with pure JavaScript, featuring:

- 📸 Screenshot-to-board OCR extraction
- ⚡ Instant backtracking solver
- 🎨 Cyberpunk glassmorphism UI
- 🧠 Client-side digit recognition engine
- 📱 Mobile-friendly controls
- 🔍 Real-time board validation

No external OCR APIs. No backend. Everything runs locally in the browser.

---

## 🚀 Features

### 📸 Screenshot OCR Extraction
Upload a Sudoku screenshot and the app automatically:
- Detects grid cells
- Extracts digits
- Populates the board instantly

Includes:
- Drag & drop image upload
- Resizable crop alignment tool
- Adaptive thresholding
- Pure JavaScript digit classification engine

---

### ⚡ Instant Sudoku Solver
Uses a high-performance recursive backtracking algorithm to solve puzzles in milliseconds.

Features:
- Real-time conflict detection
- Row/column/box validation
- Fast solving engine
- Visual solved-state animations

---

### 🎨 Futuristic UI
Designed with a cyberpunk-inspired interface:
- Glassmorphism panels
- Neon accents
- Responsive layout
- Animated interactions
- Mobile keypad support

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Python (reference solver)

No frameworks used.
